# Polymarket Arbitrage Bot 🤖

Бот для сканирования рынков Polymarket, поиска арбитражных возможностей и генерации торговых сигналов.

## Возможности

- **Арбитражный сканер** — находит рынки, где YES + NO < 1.0 (гарантированная прибыль)
- **Мульти-outcome арбитраж** — сканирует события с несколькими исходами
- **Торговые сигналы** — анализ недооценённых/переоценённых рынков
- **Momentum-сигналы** — обнаружение аномальных объёмов торгов
- **Live мониторинг** — непрерывное отслеживание рынков в реальном времени
- **CLOB Orderbook** — точные цены через стакан заявок

## Быстрый старт

### Поиск арбитража (основная функция)
```bash
# Быстрый скан по ценам Gamma API
polybot arbitrage

# Точный скан через CLOB orderbook
polybot arbitrage --use-orderbook

# С настройками
polybot arbitrage --min-profit 1.0 --max-markets 500 --min-volume 1000
```

### Торговые сигналы
```bash
# Генерация сигналов
polybot signals

# С повышенной уверенностью
polybot signals --min-confidence 0.75 --top 10
```

### Полный скан (арбитраж + сигналы)
```bash
polybot scan
polybot scan --max-markets 500 --min-profit 0.3
```

### Live мониторинг
```bash
# Непрерывный мониторинг каждые 60 секунд
polybot monitor

# С интервалом 30 секунд
polybot monitor --interval 30 --min-profit 0.3
```

### Информация о рынке
```bash
polybot market <slug>
# Пример: polybot market will-bitcoin-reach-100k
```

## Как работает арбитраж

На Polymarket каждый рынок имеет исходы YES и NO. Если:
- YES стоит 0.45 (45 центов)
- NO стоит 0.50 (50 центов)
- **Итого: 0.95** (< 1.00)

Купив ОБА исхода за 0.95, вы **гарантированно получаете 1.00** при закрытии рынка.
Прибыль: **5.26%** без риска.

### Мульти-outcome арбитраж

Для событий с несколькими исходами (например, "Кто победит?"):
- Кандидат A: YES = 0.30
- Кандидат B: YES = 0.25
- Кандидат C: YES = 0.35
- **Итого: 0.90** (< 1.00)

Купив YES на ВСЕХ кандидатов за 0.90, один из них гарантированно выиграет = 1.00.
Прибыль: **11.1%**.

## Типы сигналов

| Тип | Описание | Риск |
|-----|----------|------|
| `ARBITRAGE` | YES + NO < 1.0, безрисковая прибыль | Низкий |
| `UNDERVALUED` | Рынок недооценён (сумма цен < 0.98) | Средний |
| `OVERVALUED` | Рынок переоценён (сумма цен > 1.02) | Средний |
| `MOMENTUM` | Аномальный объём торгов (>3x от среднего) | Высокий |

## Конфигурация

Через переменные окружения (или `.env` файл):

```env
# Пороги арбитража
MIN_PROFIT_PCT=0.5         # Минимальный % прибыли
MAX_PRICE_SUM=0.995        # Максимальная сумма цен
MIN_LIQUIDITY=1000         # Минимальная ликвидность
MIN_VOLUME_24H=500         # Минимальный 24ч объём

# Настройки сигналов
MIN_CONFIDENCE=0.6         # Минимальная уверенность
SCAN_INTERVAL_SEC=30       # Интервал сканирования

# Ограничения
MAX_MARKETS_PER_SCAN=500   # Макс. рынков за скан

# Торговля (опционально — требуется приватный ключ)
POLYMARKET_PRIVATE_KEY=    # Приватный ключ кошелька
POLYMARKET_FUNDER_ADDRESS= # Адрес финансирования
MAX_BET_SIZE_USD=50        # Макс. размер ставки
AUTO_TRADE=false           # Автоматическая торговля
```

## API

Бот использует два публичных API Polymarket:

- **Gamma API** (`gamma-api.polymarket.com`) — метаданные рынков, цены, события
- **CLOB API** (`clob.polymarket.com`) — стакан заявок, точные цены, мидпоинты

Аутентификация **не требуется** для чтения данных.
