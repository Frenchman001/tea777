# Polymarket Profit Maximizer Bot 🤖💰

Продвинутый бот для максимизации прибыли на Polymarket: арбитраж, Kelly Criterion, учёт комиссий, кросс-маркет корреляции, smart alerts.

## Возможности

- **Profit Maximizer** — комбинированный скан: арбитраж + сигналы + корреляции + скоринг
- **Kelly Criterion** — оптимальный размер ставки для максимизации долгосрочной прибыли
- **Учёт комиссий 2026** — точный расчёт Polymarket taker fees по категориям
- **Арбитражный сканер** — находит рынки, где YES + NO < 1.0 (гарантированная прибыль)
- **Мульти-outcome арбитраж** — сканирует события с несколькими исходами
- **Кросс-маркет корреляции** — поиск связанных рынков с расхождением цен
- **Smart Alerts** — приоритизированные алерты по ожидаемой прибыли
- **Orderbook анализ** — slippage estimation и глубина стакана
- **Скоринг рынков** — комбинированная оценка (EV, ликвидность, время, объём)
- **Торговые сигналы** — анализ недооценённых/переоценённых рынков
- **Live мониторинг** — непрерывное отслеживание в реальном времени

## Как работает Profit Maximizer

### 1. Kelly Criterion (Критерий Келли)

Оптимальная формула для размера ставки:

```
f* = (p × b - q) / b
```
- `p` = реальная вероятность выигрыша
- `q` = 1 - p
- `b` = коэффициент (payout / stake - 1)

Бот рассчитывает **half-Kelly** (рекомендованный) для баланса между ростом и риском.

### 2. Учёт комиссий Polymarket 2026

| Категория | Fee Rate | Пик (50%) | Maker Rebate |
|-----------|----------|-----------|--------------|
| Crypto | 0.072 | 1.80% | 20% |
| Sports | 0.030 | 0.75% | 25% |
| Politics | 0.040 | 1.00% | 25% |
| Finance | 0.040 | 1.00% | 50% |
| Geopolitics | 0 | 0% | — |

Формула: `fee = shares × price × feeRate × (p × (1−p))^exponent`

### 3. Скоринг рынков (0-10)

| Компонент | Вес | Описание |
|-----------|-----|----------|
| EV Score | 40% | Expected Value после комиссий |
| Volume Score | 25% | Объём торгов 24ч |
| Liquidity Score | 20% | Глубина рынка |
| Time Score | 15% | Время до закрытия |

### 4. Кросс-маркет корреляции

Находит ценовые расхождения:
- **TIMELINE**: "BTC $100k by June" дороже чем "BTC $100k by December" — нелогично
- **THRESHOLD**: "BTC $150k" дороже чем "BTC $100k" — нелогично
- **CONDITIONAL**: Условные рынки с расхождением от базовых

### 5. Smart Alerts (приоритеты)

| Приоритет | Тип | Описание |
|-----------|-----|----------|
| CRITICAL | Арбитраж | Гарантированная прибыль |
| HIGH | Корреляции, Сигналы | Сильное расхождение цен |
| MEDIUM | Скоринг | Хороший EV после комиссий |
| LOW | Слабые сигналы | Мониторинг |

## Как работает арбитраж

На Polymarket каждый рынок имеет исходы YES и NO. Если:
- YES стоит 0.45 (45 центов)
- NO стоит 0.50 (50 центов)
- **Итого: 0.95** (< 1.00)

Купив ОБА исхода за 0.95, вы **гарантированно получаете 1.00** при закрытии рынка.
Прибыль: **5.26%** без риска.

### Мульти-outcome арбитраж

Для событий с несколькими исходами (например, "Кто победит?"):
- Кандидат A: YES = 0.30
- Кандидат B: YES = 0.25
- Кандидат C: YES = 0.35
- **Итого: 0.90** (< 1.00)

Купив YES на ВСЕХ кандидатов за 0.90, один из них гарантированно выиграет = 1.00.
Прибыль: **11.1%**.

## Типы сигналов

| Тип | Описание | Риск |
|-----|----------|------|
| `ARBITRAGE` | YES + NO < 1.0, безрисковая прибыль | Низкий |
| `UNDERVALUED` | Рынок недооценён (сумма цен < 0.98) | Средний |
| `OVERVALUED` | Рынок переоценён (сумма цен > 1.02) | Средний |
| `MOMENTUM` | Аномальный объём торгов (>3x от среднего) | Высокий |

## API

Бот использует два публичных API Polymarket:

- **Gamma API** (`gamma-api.polymarket.com`) — метаданные рынков, цены, события
- **CLOB API** (`clob.polymarket.com`) — стакан заявок, точные цены, мидпоинты

Аутентификация **не требуется** для чтения данных.
